# V1.9.16 — Browser-first TV memory

## Goal
History, channel list (custom), favorites and last channel must survive full page reload on the user browser — never start from scratch.

## Done
1. localStorage keys: `pi_vintage_history`, `pi_vintage_favorites`, `pi_vintage_last_channel`, `pi_vintage_volume`, `pi_vintage_muted` (plus existing country/channels/lang/model/bw).
2. On every channel play: write history + lastChannel to localStorage first, then POST server.
3. Favorites toggle: write localStorage first, then server.
4. Boot: paint history UI from local immediately; merge server when available; restore last channel from local if server empty.
5. Volume/mute restored on load; `volumechange` persists.
6. Custom channels path unchanged (already local + server).
7. Version 1.9.16, CHANGELOG, AI knowledge note.

## Not changed
- HLS player, IPTV import, AI/Feedback modules, UI layout, default channel packs, security (safe-fetch/SSRF).

## Deferred
- IndexedDB for very large playlists (localStorage 5MB is enough for typical use).
- Per-profile multi-user on one browser.
